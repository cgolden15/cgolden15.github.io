Project 01

Concrete Strength Predictions

Predicting the strength of concrete based on mix ratio using RFR models through Sklearn.

  • Python
  • Scikit-Learn

Project Description

For my freshman year Computational Thinking and Data Science(ENGR 1330) final, we had to take a given set of data about concrete strength based on mix ratio and create an python program that could predict the strength of other mixtures, created by the user. To do this, we used a variety of libraries such as Pandas, matplotlib, SeaBorn, Sklearn and more, to build RFR models and analyze their results to calculate the most optimal concrete mix ratio.
